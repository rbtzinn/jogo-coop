# Pedidos ao ChatGPT/Codex: balão de reviver e parry dos personagens

Um pedido por folha (palhaço e acrobata separados). Colar o bloco inteiro.

## Balão (caído) — `palhaco_balao.png` e `acrobata_balao.png`

```
IMPORTANT: Only create image files. Do not modify, move or delete any other file. Do not run any git command.

Save INSIDE the project at exactly: docs/referencias/pecas/palhaco_balao.png (for the acrobat: docs/referencias/pecas/acrobata_balao.png). Canvas exactly 2048 x 1024, grid of 4 columns x 2 rows, cells of 512 x 512, one frame per cell, left to right, top row first. Fully TRANSPARENT background (real alpha), no grid, no text, no shadows. Nothing crosses into another cell.

References: docs/referencias/pecas/palhaco_folha.png (clown) or docs/referencias/pecas/acrobata_folha.png (acrobat) for the character's face, hat/hair and colors; same 1930s rubber-hose ink style.

The character was knocked out and became a circus BALLOON: a round PINK balloon (#ff5fa2, glossy highlight, thick dark outline) whose front IS the character's face (same eyes, nose, hat/bun, hair as the reference), with a little knot and a curly string hanging below. The balloon is about 300 px wide and centered in the cell; the string hangs down about 150 px.

FACIAL EXPRESSIONS ARE IMPORTANT, different in each frame (exaggerated cartoon acting):
Frames 1-4, floating loop (balloon gently squashing and stretching, string swaying): 1 worried, eyebrows up, looking down for help; 2 pleading puppy eyes, mouth wobbling; 3 blink (eyes closed), small sigh; 4 calling out, mouth open "help!", one hand-like bump waving.
Frames 5-6, being saved by a parry: 5 surprised and happy, eyes wide, big open smile, balloon starting to stretch; 6 the balloon popping into pink confetti and stars with the character's happy face in the middle.
Cells 7-8: leave fully transparent.
```
