Política de privacidade

Respeitável Público · atualizada em 13 de outubro de 2026

Respeitável Público é um jogo gratuito, sem conta, sem anúncios e sem coleta de dados para estatística ou publicidade. Esta página explica o que acontece com informações técnicas quando você joga.

O que fica no seu aparelho

O progresso (chefões vencidos, área atual, ingressos e itens) e as configurações ficam salvos só no seu aparelho, na pasta de dados do jogo. Nada disso é enviado para nós.

Jogar online por código de sala

Para jogar em dupla com código, o jogo se conecta a um servidor de salas hospedado no Render (Estados Unidos). Esse servidor só repassa as mensagens da partida entre os dois jogadores e guarda a sala na memória enquanto ela está aberta. Ele não grava o conteúdo das partidas nem mantém histórico de quem jogou. Como em qualquer conexão pela internet, o provedor de hospedagem pode registrar dados técnicos, como o endereço IP, conforme a política de privacidade dele.

Jogar online por IP (PC)

Na conexão direta por IP, os dois computadores se conectam sem passar pelo nosso servidor. O outro jogador fica sabendo do seu endereço IP, porque é ele que vocês usam para se conectar.

Atualizações

As versões baixadas pelo site ou pelo GitHub consultam o GitHub ao abrir, para saber se há versão nova. O GitHub recebe essa consulta como qualquer acesso a um site. A versão da Microsoft Store não faz essa consulta; as atualizações dela vêm pela própria Store.

Este site

O site é hospedado na Vercel e usa fontes do Google Fonts. Ele consulta o GitHub para mostrar a versão mais nova e guarda no seu navegador apenas o idioma escolhido. Não usa cookies de rastreamento.

Crianças

O jogo não pede nem guarda dados pessoais de ninguém, inclusive de crianças.
