# Respeitável Público

Jogo de ação para um ou dois jogadores, feito na Godot. A aventura passa pelo parque do circo e pela ilha do Vulcão, com Palhaço e Acrobata, plataformas, chefões em três fases e progressão salva.

## Jogar no Windows

Na versão exportada, extraia o ZIP e abra `RespeitavelPublico.exe`. O executável contém os recursos do jogo e funciona sem instalar a Godot. No mesmo PC, os saves continuam na pasta de dados do jogo.

Para jogar em dupla, os dois devem usar a mesma versão. Um escolhe **Hospedar partida** e o outro **Entrar na partida**, com o endereço do host. Os controles podem ser alterados em **Configurações**.

Controles padrão: WASD ou setas para mover, Espaço/Z para pular, J/X para atirar, K/Shift para dash, L/C para travar a mira e I/V para especial.

## Abrir o projeto

Abra `project.godot` na Godot 4.7.2 e pressione F5. O preset **Windows Desktop** gera a versão para Windows. Os testes ficam em `tests/` e a descrição das lutas em `docs/bosses.md`.
